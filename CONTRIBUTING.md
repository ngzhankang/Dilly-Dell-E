# Contributing

## Branch Naming

| Type | Pattern | Example |
|------|---------|---------|
| Feature | `feat/<short-description>` | `feat/user-auth` |
| Bug fix | `fix/<short-description>` | `fix/login-redirect` |
| Chore | `chore/<short-description>` | `chore/update-deps` |

## Commit Convention

Follow [Conventional Commits](https://www.conventionalcommits.org/):

```
feat: add OAuth login
fix: correct token expiry calculation
docs: update setup instructions
chore: bump typescript to 5.4
```

## Pull Requests

- Open a PR against `main`
- Fill in the PR template checklist
- At least one teammate review before merging
- Squash merge preferred to keep history clean
- **Do not force-push to main**

## AI Usage

If the hackathon requires AI disclosure, update `AI_USAGE.md` before submitting.
